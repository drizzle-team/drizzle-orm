- Fixed `expo-sqlite` not finalizing prepared statements (fixes [#4519](https://github.com/drizzle-team/drizzle-orm/issues/4519), [#4068](https://github.com/drizzle-team/drizzle-orm/issues/4068))

`expo-sqlite` now prepares a statement for every query execution and finalizes it afterwards. As a result, a query made with `.prepare()` no longer keeps a native statement between executions, and SQL errors such as a missing table are thrown on its first execution instead of by `.prepare()`.

If you patched `SQLiteStatement.prototype.executeSync` to finalize statements as a workaround for [#4068](https://github.com/drizzle-team/drizzle-orm/issues/4068), remove the patch. Drizzle now finalizes every statement itself, and with the patch in place queries throw an `Access to closed resource` error.
