# v1.0.0-rc.5

- Updated RQB filters to allow branded types in shortcut-form `eq` filter (fixes [#5298](https://github.com/drizzle-team/drizzle-orm/issues/5298))
- Fixed `$onUpdateFn` being executed without need (fixes [#5780](https://github.com/drizzle-team/drizzle-orm/issues/5780))
- Fixed `$onUpdateFn` potentially overriding explicit `null`s
- Fixed `zod` schema generator returning `unknown`-templated coerced types (fixes [#5659](https://github.com/drizzle-team/drizzle-orm/issues/5659))
- Fixed `mysql2` constructor setting param in potentially undefined mistyped config (fixes [#5972](https://github.com/drizzle-team/drizzle-orm/issues/5972))
- Fixed non-jit mapper nullification triggering on single null column (fixes [#1603](https://github.com/drizzle-team/drizzle-orm/issues/1603))
- Preserved qualifiers for column chunks of `sql` fields in selection when non-current table's column is referenced (fixes [#5734](https://github.com/drizzle-team/drizzle-orm/issues/5734)) 
- Optimized query building, mapper generation
- Allowed empty returns in callback-style `orderBy`, `extras`, `RAW` of relational queries
- Removed unused `_` field in `RelationsHelperStatic`
- Restricted `undefined` value passed to fields in `where` - now throws an error upon encountering `undefined` in filters, added `EmptyFilter` symbol that can be used as an explicit replacement of `undefined` where possibly absent filter is desired by design rather than possible bug (fixes [#5636](https://github.com/drizzle-team/drizzle-orm/issues/5636))
- Fixed naming: `isReversed` to `isFilterReversed` in `Relation`
- `objects`, `arrays` `db.execute` modes (bypasses [#4464](https://github.com/drizzle-team/drizzle-orm/issues/4464))
- Fixed jit mapper nullifying nested selection objects with columns from different tables
- Updated `postgres` codecs: now generic codecs contain only in-json codecs (mirroring `mysql`), contents of drivers' codecs remain unchanged
- Made nested select join nullification consider `SQL` field data during nullification
- Deeply nested selection nullification (joined view or subquery)
- Fixed `geometry`, `geography` & `box` array types data getting reduced to one item due to wrong delimiter used during `pgArray` construction\parsing
- Added delimiter customization to `makePgArray`, `parsePgArray` utilities
- Optional explicit column lists for `db.insert` (workaround for [#5001](https://github.com/drizzle-team/drizzle-orm/issues/5001), [#5309](https://github.com/drizzle-team/drizzle-orm/pull/5309))
- Transaction snapshot support for `pg` dialect
- Fixed `pg` transaction config related errors on empty but present config
- Supported transaction config in effect `pg` drivers
- Bumped `tursodatabase` library versions
- Supported transaction configs for `tursodatabase` drivers
- Fixed `mysql` transaction options being joined on wrong separator
- Supported `isolationLevel` in `bun-sql/mysql` transactions
- Removed transaction config from `effect-sqlite`, `effect-mysql` due to lack of support in drivers
- Explicit error throws on unsupported transaction configs
- Partial transaction config support for `libsql`, `tidb` drivers
- Improved error messages on unknown fields in RQBv2 selection (fixes [#5367](https://github.com/drizzle-team/drizzle-orm/issues/5367))
- Fixed `op-sqlite` transaction being handled as synchronous
- Fixed broken `op-sqlite` query executors (fixes [#5936](https://github.com/drizzle-team/drizzle-orm/issues/5936))
- Bumped `op-sqlite` to v17 (fixes [#5928](https://github.com/drizzle-team/drizzle-orm/issues/5928))
- Fixed `expo-sqlite` not finalizing prepared statements
- Added `expo-sqlite/async` for async querying (fixes [#5240](https://github.com/drizzle-team/drizzle-orm/issues/5240))
- Added local `sha256` hash function as a fallback for cache query hashing in environments without `globalThis.crypto` available
- Fixed dynamic query builders blocking query builder's variable reassignment after applying nullable joins by defaulting to `not-null` behavior on not yet joined column groups in selection (fixes [#4232](https://github.com/drizzle-team/drizzle-orm/issues/4232))
- Fixed `bytea` not being included in `pg` table creation callback format column list
- Fixed `sqlite` ignoring `.$defaultFn(...)` on insert when `.default(...)` is present
- Removed `SQL.usedTables` calculation from constructor to getter
- Fixed false relation name collision error and relational filter misrouting for relation names shadowing `Object.prototype` properties like `constructor` (fixes [#6076](https://github.com/drizzle-team/drizzle-orm/issues/6076))
- Updated `neon-http` migrator to automatically rollback failed migrations
- Bumped `effect` to `4.0.0-beta.105`
- Improved hash for query name generation & query cache key
- Fixed internal type errors in built code
- Bumped `typebox` to `1.2.0` (fixes [#5981](https://github.com/drizzle-team/drizzle-orm/issues/5981))
- Updated `mssql`, `cockroach`, `singlestore` sessions to new format
- Added missing `lateral` (`apply`), `cross` joins, `insert ... select`, `db.$count` to `mssql`
- Added explicit error on attempt to insert multiple default-only rows in `mssql`
- Fixed [[BUG]: inArray/notInArray empty arrays do not work with SQL Server](https://github.com/drizzle-team/drizzle-orm/issues/5632)
- Fixed [[BUG]: node-postgres pool client is not released when transaction BEGIN rejects](https://github.com/drizzle-team/drizzle-orm/issues/6023)
- Fixed [Batch insert crashes with RangeError when row-count × column-count exceeds ~8 k rows × 15 cols (~120 k params)](https://github.com/drizzle-team/drizzle-orm/issues/5994)
- Fixed [[BUG]: Composition of not and or/and yields compile error](https://github.com/drizzle-team/drizzle-orm/issues/4160)
