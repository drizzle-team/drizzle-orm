# v1.0.0-rc.6

Breaking changes:
- `postgres` snapshot format bumped to 10 following removal of `.concurrently()` from `drizzle-orm` `pg` indexes: `concurrently` is dropped from format 9 index entries and index `create` / `alter` deltas on upgrade
- `drizzle-kit` is published as ESM only: the `drizzle-kit` binary, `drizzle-kit/api-*`, `drizzle-kit/cli` and `drizzle-kit/payload/*` entries lost their CommonJS builds and `require` export conditions. Added `engines.node`: `^20.19.0 || >=22.12.0` - Node versions that can `require()` ES modules

Improvements:
- Faster `pull` / `push` introspection on large schemas (PostgreSQL, CockroachDB, MySQL, SQLite, MSSQL) and faster PostgreSQL schema diffing
- `pull` errors now carry their underlying cause for every dialect: printed after the message in text output, returned as `error.cause` in JSON output
- MSSQL `pull` returns indexes sharing one name across tables in a stable order
